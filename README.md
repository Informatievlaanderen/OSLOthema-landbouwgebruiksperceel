# Landbouwgebruikspercelen

## Inleiding

Het traject Landbouwgebruikspercelen streeft naar het ontsluiten van de data rond gebruik van percelen voor landbouwtoepassingen. De percelen zelf zijn open data die ontsloten worden met een AGPAKEY die hier gebruikt is om de privatieve informatie over de percelen mee te koppelen.

Dankzij deze ontsluiting kunnen afnemers, die de nodige machtigingen bezitten, snel en makkelijk de persoon of onderneming opzoeken die het landbouwgebruiksperceel exploiteert op een bepaald moment.

## Verslagen en presentaties

De verslagen en presentaties van dit traject kan je terugvinden op het [Standaardenregister](https://data.vlaanderen.be/standaarden).
